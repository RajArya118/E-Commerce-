## Technical Risks & Mitigations

1. **Database Availability**:
   - *Risk*: MongoDB local daemon may not be active on arbitrary developer machines.
   - *Mitigation*: Motor connection manager supports seamless cloud connection to MongoDB Atlas, with an automatic in-memory fallback (`mongomock-motor`) during automated test runs.
2. **Payment Gateway Verification**:
   - *Risk*: Frontend payment manipulation or man-in-the-middle tampering.
   - *Mitigation*: All payment states are locked on the backend. The backend independently verifies the cryptographic HMAC-SHA256 signature generated by Razorpay before fulfilling any order.
3. **AI Catalog Accuracy**:
   - *Risk*: Large Language Models can invent non-existent products, prices, or inventory levels.
   - *Mitigation*: Grounded RAG approach. The system passes live, sanitized product catalog snapshots into the prompt context, and post-validates all recommended product IDs against the database.
4. **Animation Performance (60 FPS Target)**:
   - *Risk*: 3D canvases and heavy GSAP triggers can cause jank on mobile or low-power hardware.
   - *Mitigation*: Progressive enhancement. Support `prefers-reduced-motion`, implement WebGL feature detection, and utilize CSS GPU-accelerated transforms (`translate3d`, `will-change`).
